# 🤖 AI DevOps Support Assistant

A Flask-based DevOps Support Assistant designed to help troubleshoot common IT and DevOps problems.

## 🚀 Features

- 🐳 Docker troubleshooting
- 🐧 Linux troubleshooting
- ☁️ AWS troubleshooting
- ☸️ Kubernetes troubleshooting
- 🔀 Git & GitHub troubleshooting
- 🔧 Jenkins & CI/CD troubleshooting
- 🌐 Networking troubleshooting
- 💻 IT Support troubleshooting
- 🛠️ Practical troubleshooting commands
- 📚 Beginner-friendly explanations
- 🐳 Dockerized application

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Docker
- Git

- Linux
- AWS

- Jenkins / CI/CD
